# Python / FastAPI — 5W2H
- **What?** Typed HTTP routes, Pydantic request validation, SQLAlchemy Core for SQLite/PostgreSQL.
- **Why?** Learn JSON contracts and direct persistence with minimal boilerplate.
- **Who?** React Native clients or curl; any client can send HTTP requests.
- **When?** Start here to learn status codes and transactions before adding queue/Redis.
- **Where?** `app/main.py` controls HTTP rules; `app/store.py` owns SQL and fixtures.
- **How?** Pydantic → FastAPI → SQLAlchemy connection → row lock → SQL commit → JSON.
- **How much?** SQLite locally free; PostgreSQL local via Docker; managed hosting incurs fees.

**ELI15:** Your phone is the customer, the API is a cashier, SQL tables are the books, and a transaction is the rule that either *all* book entries are written or *none* are. The idempotency key is a receipt number: scanning it twice must not charge twice.

Run: `pip install -r requirements.txt && uvicorn app.main:app --port 8000`; tests: `pytest -q`; docs: `http://localhost:8000/docs`. For PostgreSQL set `DATABASE_URL=postgresql+psycopg://northstar:northstar@localhost:5432/northstar_python`.
