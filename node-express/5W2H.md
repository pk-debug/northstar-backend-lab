# Node.js / TypeScript — 5W2H
**What?** HTTP endpoints with Express 5, Zod validation, a database repository with native SQLite or pg pool.
**Why?** Learn promises, non-blocking I/O, SQL query parameters, and the event loop.
**Who?** The Northstar React Native Expo client and interviewers reviewing your code.
**When?** Good after Python, especially if you know TS already.
**Where?** `src/server.ts` routes and business rules; `src/db.ts` DB adapter and transactions.
**How?** Middleware → Zod parsing → transaction → row lock → SQL → JSON; for SQLite, a promise queue avoids overlapping transaction sessions.
**How much?** Local SQLite is free; `docker compose` PostgreSQL is locally hosted.

**ELI15:** `await` means "while the database is busy, Node can work on other HTTP requests." That is useful for scalability, but you must still protect concurrent BUYs from spending the same money twice with DB locking. SQLite's single-writer rule is simpler than PostgreSQL row locking.

Run: `npm install && npm run dev`; TS checking: `npm run check`; default port 3000. PostgreSQL: `DATABASE_URL=postgres://northstar:northstar@localhost:5432/northstar_node npm run dev`.
