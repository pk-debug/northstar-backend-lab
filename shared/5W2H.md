# Five Ws and two Hs: the whole learning lab

**WHAT?** Five independently runnable, independently persisted implementations of the *same* demo stock portfolio REST API.

**WHY?** To learn what is constant across backends (HTTP contract, validation, SQL transactions, idempotency) and what differs (language, frameworks, dependency injection, concurrency, database drivers).

**WHO?** A mobile engineer moving into backend roles; all services are demo-only, single-account prototypes, not multi-user applications.

**WHEN?** Start Python or Node for request/response fluency, build Java for enterprise transactions, Kotlin for JVM/coroutines, and Go for explicit concurrency; integrate mobile once GET and POST tests pass.

**WHERE?** Runs on a laptop (localhost); Android emulator reaches host at `10.0.2.2`, physical phones need a reachable LAN IP. Deploy only after security improvements.

**HOW?** HTTP route → parse/validate → service → transaction → SQL → commit → JSON DTO. Read every module's `5W2H.md`, inspect docstrings/comments, set environment variables, run integration tests.

**HOW MUCH?** Local SQLite has no hosted DB cost. Dockerized PostgreSQL/Redis/Mongo consumes local machine resources; cloud databases, egress, market feeds, managed services, backups and observability may cost money. Code is instructional, not a financial product.
