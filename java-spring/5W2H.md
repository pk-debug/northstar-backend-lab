# Java / Spring Boot — 5W2H
- **What?** Spring REST controller + service + constructor injection + JDBC transactions.
- **Why?** Learn mature enterprise patterns and database row locking.
- **Who?** A mobile client / interview evaluator reviewing clear separation of concerns.
- **When?** After understanding HTTP and SQL; important for Java backend interviews.
- **Where?** `ApiController.java` = HTTP; `LedgerService.java` = rules/transactions; `Market.java` = market fixture.
- **How?** Route → input checks → @Transactional service → SELECT FOR UPDATE → JDBC update → response.
- **How much?** Local H2 file, no bill; PostgreSQL in local Docker or managed pricing.

**ELI15:** The Spring controller is the waiter, the service is the chef applying rules, and JdbcTemplate is the waiter who writes to the accounting book. `@Transactional` means the buy either updates shares, cash *and* history, or rolls everything back. `SELECT FOR UPDATE` prevents two requests from spending the same cash simultaneously.

Requires Java 21 and Maven. Run `mvn spring-boot:run`, test `mvn test`, default port 8081. PostgreSQL variables: `DATABASE_URL=jdbc:postgresql://localhost:5432/northstar_java`, `DB_USER=northstar`, `DB_PASSWORD=northstar`.
