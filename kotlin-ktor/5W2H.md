# Kotlin / Ktor — 5W2H
**What?** Kotlin's lightweight Ktor server, JSON serialization and JDBC ledger service.
**Why?** Reuse Kotlin strengths from Android while learning server-side boundaries.
**Who?** React Native Expo clients and Android/backend job interviewers.
**When?** After learning request/response and SQL; then explore suspending non-blocking database APIs.
**Where?** `Application.kt` routes and validation; `Market.kt` DTOs; `Store.kt` transactions.
**How?** Ktor pipeline → strict JSON → JDBC pool → SELECT FOR UPDATE → commit.
**How much?** Local H2 database is free; Docker PostgreSQL requires local resources.

**ELI15:** A Ktor route is similar to an Android navigation destination, except the input is an HTTP request and the result is JSON. JDBC is a *blocking* database API, so this learning app deliberately does not pretend it is fully non-blocking just because Kotlin supports coroutines. Explore R2DBC and thread pools later.

Requires Java 21, Gradle 8.14+ installed. Run `gradle run`, `gradle test`. PostgreSQL variables: `DATABASE_URL=jdbc:postgresql://localhost:5432/northstar_kotlin`, `DB_USER=northstar`, `DB_PASSWORD=northstar`.
