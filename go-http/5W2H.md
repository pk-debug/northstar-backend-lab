# Go / net/http — 5W2H
- **What?** Standard library router and `database/sql` with two database drivers.
- **Why?** Learn interfaces, structs, contexts, error handling and explicit transactions rather than an all-in-one framework.
- **Who?** Your React Native app, via JSON HTTP.
- **When?** After one backend is familiar: contrast explicit Go with annotation-heavy Spring.
- **Where?** `cmd/server/main.go` routes, SQL and rules; `internal/data/` embeds exact quote fixtures.
- **How?** `http.NewServeMux` → strict `json.Decoder` → transaction → SQL → JSON.
- **How much?** Start SQLite locally; PG in free local Docker (cloud may charge).

**ELI15:** In Go, you write many checks yourself: every `err != nil` is like checking the receipt after each operation. `context.Context` means a cancelled phone request can cancel DB work. The SQL pool controls connection reuse. Start with Go 1.23+ and run `go mod tidy && go run ./cmd/server`, test with `go test ./...`. For PG set `DATABASE_URL=postgres://northstar:northstar@localhost:5432/northstar_go`.
